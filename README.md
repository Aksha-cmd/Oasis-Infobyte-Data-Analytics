## 🚀 Project Overview

This repository contains the completed Level 1 data analytics and machine learning pipelines developed during the Oasis Infobyte Internship track. The projects focus on end-to-end data processing, exploratory analysis, and customer segmentation.

### 📂 Repository Structure

*   **`project1_eda.ipynb`**: Automated Exploratory Data Analysis (EDA) on retail sales data, featuring comprehensive seasonal trends and demographic spend analysis.
*   **`project2_segmentation.ipynb`**: Unsupervised machine learning pipeline using K-Means Clustering to group customers based on spending patterns and behavior.
*   **`project4_cleaning.ipynb`**: A structured data preprocessing and cleaning pipeline that handles missing values, deduplication, and outlier visualization.
*   **`retail_sales_dataset.csv` & `menu.csv`**: The underlying transactional and product datasets used across the analytics pipelines.

---

## 🔍 Key Insights & Highlights

*   **Sales Consistency:** Time-series analysis reveals highly stable retail baseline revenue patterns with zero volatile seasonal drops across quarters.
*   **Demographic Target Metrics:** Spending behavior across core sectors (Electronics, Clothing, and Beauty) shows near-identical parity between demographics, proving product utility drives conversion over gender.
*   **Advanced Modeling:** Applied the Elbow Method and Silhouette analysis to optimize customer clustering for precision marketing campaigns.
