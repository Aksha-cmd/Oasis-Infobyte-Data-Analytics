# Oasis Infobyte Data Analytics Internship

Welcome to my Data Analytics internship repository! This repository contains all the tasks and projects I completed during my Data Analytics internship at Oasis Infobyte. The projects are divided into two levels, progressing from fundamental data manipulation to advanced machine learning models.

## 🚀 Technologies & Tools Used
* **Language:** Python
* **Libraries:** Pandas, NumPy, Matplotlib, Seaborn, Scikit-Learn, NLTK
* **Environment:** Jupyter Notebook / VS Code
* **Version Control:** Git & GitHub

---

## 📂 Level 1 Projects (Foundations of Data Analytics)
This level focuses on the core principles of data handling, cleaning, and extracting actionable insights through Exploratory Data Analysis (EDA).

* **Exploratory Data Analysis (EDA)**
  * **File:** `project1_eda.ipynb`
  * **Description:** Conducted deep-dive exploratory data analysis to uncover trends, patterns, and anomalies in the raw dataset using data visualization techniques.
  
* **Customer Segmentation**
  * **Files:** `project2_segmentation.ipynb` & `marketing-analytics-customer-segmentation.ipynb`
  * **Description:** Applied clustering techniques to segment customers based on purchasing behavior and demographics for targeted marketing strategies.

* **Data Cleaning & Preparation**
  * **File:** `project4_cleaning.ipynb`
  * **Description:** Handled missing values, outliers, and inconsistent formatting to transform raw, messy data into a structured format ready for machine learning algorithms.

---

## 🧠 Level 2 Projects (Advanced Machine Learning)
This level introduces complex datasets and predictive modeling, utilizing supervised and unsupervised machine learning algorithms.

* **House Price Prediction**
  * **File:** `level2_house_prices.ipynb`
  * **Description:** Built a regression model to predict housing prices based on various structural and locational features.

* **Wine Quality Prediction**
  * **File:** `level2_wine_quality.ipynb`
  * **Description:** Developed a classification model to predict the quality of wine based on its physicochemical tests and chemical makeup.

* **Credit Card Fraud Detection**
  * **File:** `level2_fraud_detection.ipynb`
  * **Description:** Created a robust machine learning model to identify fraudulent credit card transactions within a highly imbalanced dataset.

* **Android App Market Analysis**
  * **File:** `level2_android_market.ipynb`
  * **Description:** Analyzed the Google Play Store dataset to identify key factors that drive app engagement, downloads, and user ratings.

* **Autocomplete & Autocorrect Application**
  * **File:** `level2_autocomplete_autocorrect.ipynb`
  * **Description:** Implemented Natural Language Processing (NLP) concepts to build a text recommendation and spell-correction algorithm.
